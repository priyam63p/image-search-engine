# Image Search Engine

A web application that allows users to search for images using keywords, fetch high-quality results via API, and view or download them seamlessly.

---

## 🚀 Features

* **Keyword Search:** Search for any image using descriptive keywords.
* **Responsive Grid Layout:** Clean, mobile-friendly design displaying image cards in a balanced layout.
* **Load More / Pagination:** Easily fetch additional search results without page reloads.
* **Direct Image Links:** Click on images to view them in full resolution or navigate to their source pages.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API:** [Unsplash API](https://unsplash.com/developers) *
